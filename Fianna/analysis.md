The dataset I made is attempting to analyze the changes in jazz style in jazz clubs around Greenwich, NoHo, and the East Village from this interactive map:
https://www.peoplesles.org/jazz-map-of-greenwich-village-the-east-village-and-noho/

I looked up the jazz styles of each club in this dataset by hand. 

The code in my analysis prints out a png of the charts made for each style of jazz that clubs primarily utilized each decade. 

One key flaw is the fact that I only included one column for style of jazz, when in reality, multiple clubs had multiple different styles and they changed throughout the decades.

I used charts to showcase this as visuals allow the user to see what's happening easier than any words could ever show. I used Claude to help me build the analysis code so we can see the changes in style easier. 

I tried to include the club rent to originally analyze gentrification and why a bunch of clubs closed in the 80's, but I couldn't find exact numbers for that. I then tried neighborhood rent to get an approximate number for that, yet couldn't find information about that either. I finally decided to switch gears and analyze the styles of jazz, and how they've changed as each club opened and closed.

The patterns are clear: traditional style jazz was in in the 30's and 40's. As we keep exploring, it becomes much less clear which style dominated the decade, as many bars spread out their styles, and allowed multiple styles of jazz to play at their venues. I wonder if the different styles of jazz at each club contributed to them closing as well, and not just rising costs? How much of an influence does style have in that?
